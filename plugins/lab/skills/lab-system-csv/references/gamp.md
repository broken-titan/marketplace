# GAMP pointers (do not dump)

Cite the current public catalog pages. Do not paste chapters, category tables, or example protocols from the books.

- **GAMP 5** 2nd edition (2022), ISPE — computerized-system validation lifecycle; critical thinking; agile-compatible; aligns with FDA Computer Software Assurance. Custom application software is Category 5. https://ispe.org/publications/guidance-documents/gamp-5-guide-2nd-edition
- **FDA CSA** — Computer Software Assurance for Production and Quality System Software (draft guidance and related CDRH pages). Use for risk-based assurance language beside IQ/OQ/PQ labels. https://www.fda.gov/regulatory-information/search-fda-guidance-documents
- **GAMP Good Practice Guide: GxP Compliant Laboratory Computerized Systems** (2nd ed., 2012) — instruments and laboratory interfaces. That overlay is `lab-informatics-compliance/references/gamp-lab-systems.md`. It is a different document from this skill's GAMP 5 package.

IQ/OQ/PQ names are conventional in many labs. GAMP 5 emphasizes critical thinking over those labels. If the consuming repo already uses CSA activity names, keep them and map them on `trace.md`.
