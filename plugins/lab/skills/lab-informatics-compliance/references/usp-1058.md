# USP ⟨1058⟩ Analytical Instrument Qualification

Load when a GxP / `pharma_qc` / `glp` flag is on, or when
`usp_1058` is adopted as design standard. GxP instrument-fitness
overlay. Paywalled: [USP store](https://www.usp.org/).

Do not invent subclause letters. Confirm the current ⟨1058⟩ text
before an audit matrix.

## Groups A / B / C

USP ⟨1058⟩ classifies instruments by how much software and
user-configured calculation they carry. Typical split (confirm
current chapter):

- **Group A** — no measurement software / no calibration in the
  GxP sense (e.g. magnetic stirrer). Qualification is visual /
  organizational.
- **Group B** — controlled measuring instruments; manufacturer
  firmware; user does not configure calculations.
- **Group C** — computerized analytical systems (CDS, user
  methods, processing parameters). Full AIQ + software
  validation overlap.

## Software consequences

- Store the **group** on the equipment object (`base-objects.md` O1).
- Group C devices must bind the reprocessable file + processing
  parameters (`base-objects.md` O6).
- DQ/IQ/OQ/PQ evidence is organizational; the system records
  qualification **status** and refuses OOC / unqualified devices
  on the write path.

Not a substitute for 21 CFR 211.68 / 211.194(d) or 17025 6.4.
