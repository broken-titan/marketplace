# Intake questions (use this wording)

Inspect `docs/tolkien-prose-profile.md` in the consuming repo first. If it
exists, show a compact summary and ask: **update** or **leave**. If leave,
stop.

Ask the closed questions below, bundled. Preselected options only — do
not invent free-text axes except the short "other" lines. Do not write a
sample table or tenant into this plugin.

## Q1 — Mode

- A. Recap (rewrite a journal / session log; fidelity; default for that job)
- B. Original fiction (invention allowed inside the other answers)
- C. NPC-voice only (mouth-cards; no plot add-ons)
- D. Recap now; keep original / NPC available later (write both into the profile)

## Q2 — Point of view and tense

- A. Third person, past
- B. Third person, present
- C. First person, past
- D. First person, present
- E. Match the source and do not change it (recap default)

## Q3 — Tone

- A. Plain walking tale
- B. Higher / more formal at turns, plain in camp and road
- C. Rustic / familiar throughout
- D. Other (one line; does not invent a metre or a language)

## Q4 — Banned words (multi)

- A. Costume padding (eldritch, ichor, tenebrous, dummy-thee)
- B. Contrast formulas ("it is not X, it is Y")
- C. Forecasts and remaining-chapter hints
- D. A list the user names (write it into the profile)
- E. None beyond this skill's standing bans

## Q5 — Mouth-cards

- A. Ask before much talk (default)
- B. Cards already in the profile or the message (use them)
- C. Proceed with scarce speech, close to the narrator

## Q6 — Mechanical residue (dice, initiative, table talk)

- A. Turn into story, or omit if it does not act (recap default)
- B. Omit entirely
- C. Keep a light trace the user describes (one line)

## Q7 — Forecast / hook

- A. None (recap default)
- B. Allowed: one closing glance forward the user specifies
- C. Allowed in original mode only

## Q8 — Spelling locale

- A. Match the source
- B. en-GB
- C. en-US
- D. Other (name the locale)
