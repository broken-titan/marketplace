# What to run

Before saying done, fixed, tests pass, or ready to PR:

1. Write down the smallest command that would show the claim is wrong (the test you added, the package suite, the typecheck the repo already uses).
2. Run it on the current tree.
3. Paste that command and the lines that show the result.

## Paste

- A test command and its summary or the failing/passing names
- A typecheck or build the repo already uses, when that is the claim
- A manual probe **only** when no automated command exists – still paste what you ran and what it printed

Do not treat as enough: "CI will catch it", a command you intended to run, or output from a tree you then changed.
