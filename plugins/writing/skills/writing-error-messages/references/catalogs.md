# Public catalogs, folded

Each source maps onto the three-part contract. Do not import a second outline.

| Source | What it adds |
|--------|----------------|
| [Google developer style — errors](https://developers.google.com/style/errors) | Problem, cause when known, action. Full sentences. No jokes. |
| [Microsoft Writing Style Guide — error messages](https://learn.microsoft.com/en-us/style-guide/text-formatting/error-messages) | Lead with what the user needs. Specific. Present tense. |
| [Apple HIG — errors](https://developer.apple.com/design/human-interface-guidelines/feedback) | Situation plus a way forward. |
| [Nielsen Norman — error-message guidelines](https://www.nngroup.com/articles/error-message-guidelines/) | Explicit, human-readable, precise, constructive. |
| [WCAG 2.2 — 3.3.1](https://www.w3.org/WAI/WCAG22/Understanding/error-identification.html) / [3.3.3](https://www.w3.org/WAI/WCAG22/Understanding/error-suggestion.html) | Identify in text; suggest a fix when known. |
| [GOV.UK — error messages](https://design-system.service.gov.uk/components/error-message/) | What happened and how to fix it. Page-level summary. |
