# Voice contrasts

Wrong is hedged or padded. Right is this voice.

Wrong: "It might be worth considering breaking larger tasks into smaller ones to potentially improve estimation accuracy."
Right: "Break tasks into small pieces. Each task should take 2 days or less. The smaller the timebox, the easier it is to estimate. Split 'payment gateway integration' into connection setup, authentication, core transactions, error handling, and refunds."

Wrong: "There are some communication challenges with the leadership team that could be improved."
Right: "Communication from IT leadership is almost non-existent. Specific questions go unanswered in email and the team chat. A director said we could talk to them about anything, but they will not respond."

Wrong: "This matters because process is more than a checklist, it is a contract."
Right: "Skip a written exit criterion and the stage silently slips. A stage is done when the named checks pass."
