# Living-spec outline

```
# <Feature> - Requirements
> What this is · companion docs · Date (absolute) · Owner · Based on (sources)
1. Overview & purpose
2. Goals
3. Stakeholders & reviewers
4. Scope  (in scope / out of scope & deferred)
5. Assumptions & constraints
6. Functional requirements        # numbered FR-*; each: ID, statement, source, verification method
7. Non-functional requirements    # NFR-* — measurable
8. Phasing - what's available at launch
9. Related documents              # SAD, RSCOP, interface specs, open-questions
```

Convert relative dates to absolute. Optionally fold user stories (`As an <actor>, I want <feature>, so that <benefit>`) into Overview/Goals to ground the FR-*.
