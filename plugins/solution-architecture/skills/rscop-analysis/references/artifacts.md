# Artifact paths (this group)

One convention under `docs/`. Do not invent a parallel tree.

| Artifact | Path | Level |
|----------|------|--------|
| NFR discovery matrix | `docs/<slug>-nfr-discovery.md` | Engagement |
| Living spec | `docs/<feature>-requirements.md` | Feature |
| Open questions (feature) | `docs/<feature>-open-questions.md` | Feature |
| RSCOP analysis | `docs/rscop-<slug>.md` | Engagement |
| Solutions Architecture Document | `docs/sad-<slug>.md` | Engagement |

**Layers.** The living spec is feature-level. RSCOP and the SAD are engagement-level. They are not two sources of truth. The living spec does not replace a SAD. Cross-link; do not duplicate NFR tables.

SOW is an input, not produced here. See the SAD skill's `references/sow-handoff.md`.
