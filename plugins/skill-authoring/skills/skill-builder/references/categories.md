# One category

Prefer one:

| Category | Fit |
|----------|-----|
| library / API reference | How to call a surface |
| product verification | Does this build match the product bar |
| data | Shapes, contracts, pipelines |
| business process | Human + system workflow |
| scaffolding | Generate a tree or starter |
| quality / review | Read-only or gated review |
| CI / CD | Pipelines, gates, promote |
| runbook | Incident or ops procedure |
| infra ops | Cluster, network, runtime |
| skill authoring | This plugin |

If a draft is two of these, split into two skills or pick the one the user invoked.
