# Description is a trigger

YAML `description` is when to run, not what the skill is.

**Shape:** “Use when &lt;situation or user ask&gt;.” Include the nouns and verbs a router will see (file types, stage names, error classes, artifact paths).

**Avoid:** a table of contents, a feature list, or “this skill helps you write better X.”

Rewrite until a stranger would invoke it from the user message alone.
