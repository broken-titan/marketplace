# Description is when to use

YAML `description` is required. It is when to run the skill, written in the same voice as the body.

Write one or two specific sentences. Do not write a slogan, a keyword dump, or a second copy of a Hard rule unless that sentence is when to use the skill.

Start from “Use when” and the situation or user ask. Include the nouns and verbs a router will see (file types, stage names, error classes, artifact paths).

A paragraph under `# Title` is not required. Keep a line there only when it is the actual first rule. Do not write a maxim, and do not restate the title or the YAML description.
